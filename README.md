# Local Bridge

Небольшое Android-приложение для локальной передачи текста и файлов между телефоном и клиентским Windows-ПК через браузер.

## Цель

Минимум действий на клиентском компьютере: без установки программы, аккаунтов и облачных серверов. Клиент открывает локальный адрес телефона в Microsoft Edge и работает через веб-интерфейс.

## Текущий этап — MVP 1

Текстовый обмен уже подтверждён на Pixel 7 / Android 17:

- Edge подключается к HTTP-серверу телефона по LAN;
- ПК → телефон записывает текст в Android clipboard;
- телефон → ПК отправляет clipboard по кнопке через SSE без F5.

Версия `0.4.0-dev` переносит сервер из `MainActivity` в Android foreground service, чтобы он продолжал работать после сворачивания/закрытия экрана приложения. В UI добавлена явная кнопка запуска/остановки сервера; foreground notification также показывает активный сервер и позволяет его остановить.

После реального PASS фоновой работы следующий этап — PIN + session. Затем отдельно проверяется hotspot Pixel 7 + Karing. Передача файлов остаётся MVP 2.

## Целевая среда

- Google Pixel 7.
- Android 17 / API 37.
- Windows + Microsoft Edge.
- APK через GitHub.
- Общая Wi-Fi/LAN; hotspot телефона проверяется отдельно.
- Karing может постоянно работать в TUN-режиме; Local Bridge исключается из его проксирования.

## Принципы

- Локальная работа без облака и внешнего сервера.
- На клиентском ПК ничего не устанавливается.
- Маленькая архитектура без лишних фреймворков.
- Проверка каждого этапа на реальном устройстве до добавления следующего.
- GitHub-репозиторий — источник истины по коду и техническим решениям.
