# Local Bridge

Небольшое Android-приложение для локальной передачи текста и файлов между телефоном и клиентским Windows-ПК через браузер.

## Цель

Минимум действий на клиентском компьютере: без установки программы, аккаунтов и облачных серверов. Клиент открывает локальный адрес телефона в Microsoft Edge и работает через веб-интерфейс.

## Текущий этап

Разработка начинается с **MVP 1 — только текст в обе стороны**.

### MVP 1

- Android запускает локальный HTTP-сервер.
- Windows-ПК открывает страницу телефона по локальному IP.
- ПК → телефон: текст из браузера записывается в системный clipboard Android.
- Телефон → ПК: пользователь открывает Local Bridge, нажимает кнопку отправки текущего clipboard, браузер получает текст без F5.
- В браузере есть кнопка копирования полученного текста.
- Сервер продолжает работать при свёрнутом приложении через foreground service.
- Базовая локальная защита: PIN + сессия.

### MVP 2

После реальной проверки MVP 1 на Pixel 7 и Windows + Edge:

- ПК → телефон: upload / drag & drop файлов.
- Телефон → ПК: Android Share → Local Bridge.
- Сохранение входящих файлов в `Download/Local Bridge`.

## Целевая среда первой проверки

- Телефон: Google Pixel 7.
- ОС: Android 17 / API 37.
- Клиент: Windows + Microsoft Edge.
- Установка Android-приложения: APK.
- Основной сценарий сети: телефон и ПК в одной Wi-Fi/LAN.
- Дополнительный сценарий после базовой проверки: ПК подключён к точке доступа телефона.
- На телефоне может постоянно работать Karing в TUN-режиме; Local Bridge предполагается исключать из его проксирования.

## Принципы проекта

- Локальная работа без облака и без внешнего интернета.
- Маленькая архитектура без лишних фреймворков и сервисов.
- Сначала доказать минимальный рабочий цикл, затем добавлять функции.
